# Vehicle Rental Management System

Acest proiect este o aplicație de tip consolă realizată în **C#**, având ca scop gestionarea închirierii vehiculelor.

## Funcționalități
- Autentificare utilizator și administrator
- Adăugare, modificare și ștergere vehicule
- Gestionarea statusului vehiculelor (Available, Reserved, Rented, InService, Unavailable)
- Rezervarea unui vehicul
- Calculul costului estimat al unei rezervări
- Vizualizarea istoricului închirierilor
- Anularea rezervărilor conform regulilor aplicației

## Concepte POO utilizate
- Încapsulare
- Moștenire
- Polimorfism
- Clase abstracte
- Enumerări (enum)

## Structura proiectului
- `User`, `Admin`, `Utilizator`
- `Vehicle`, `Car`, `VehicleStatus`
- `Reservation`, `Rental`
- `AdminService`
- `ReservationService`
- `Program`
